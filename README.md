# Bash & DevOps Shell Scripts

A collection of practical Bash shell scripts created while learning Linux administration, networking, system monitoring, automation, Docker, log analysis, and basic DevOps operations.

The repository contains beginner-friendly scripts that solve common Linux and DevOps tasks and demonstrate practical Bash scripting skills.
